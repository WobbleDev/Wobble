# features/overview/bullseye

The Assessment Bullseye: the chart of the Organizing Committee's reach into the workplace.

The geometry is load-bearing and deliberate — the bands are real annuli, the size and travel
are fixed by the viewport, and the map is dragged rather than parallaxed. Hostile sits outside the bands
(ADR 0012); re-check a dense render before simplifying any of it.

Overview draws it, but `src/routes/+layout.svelte` grounds it against the page.
